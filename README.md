# postingttii

Локальный мультипостер для коротких видео:

- 2× TikTok
- 2× Instagram Reels
- 2× YouTube Shorts
- папка `videos/inbox` как очередь на публикацию
- OpenAI генерирует описание и хештеги
- локальная панель управления в браузере

Проект использует официальные API платформ и OAuth. Секреты и токены не коммитятся в Git.

## Instagram: две Meta App + отдельные профили Microsoft Edge (Windows)

Эта ветка основана на стабильной версии с обложками Instagram и Telegram
Studio (`fix/instagram-meta-concurrency-20261009`). Tor Browser и Tor OAuth
**не используются**. Существующие авторизации и обложки не удаляются.

- **Meta 1 · Edge (основной режим):** **любой свободный Instagram-слот 1–8**
  подключается через `INSTAGRAM_CLIENT_ID`, `INSTAGRAM_CLIENT_SECRET`,
  `INSTAGRAM_REDIRECT_URI`. Это работает и для новых аккаунтов в слотах 6–8.
- **Meta 2 · Edge (совместимость):** ранее подключённые аккаунты в слотах 6–8
  остаются со своими токенами. Второе приложение доступно опционально через
  `INSTAGRAM_CLIENT_ID_2`, `INSTAGRAM_CLIENT_SECRET_2`,
  `INSTAGRAM_REDIRECT_URI_2`.

Для каждого Instagram-слота Edge запускается с отдельным постоянным
`user-data-dir` в `data/edge_instagram_profiles/slot_N`. Повторное открытие
слота использует **тот же профиль**. При первом подключении Instagram
попросит войти и дать доступ Meta-приложению через официальный OAuth.
Вход в Edge сам по себе не означает, что приложение может публиковать:
аккаунт станет «Подключён» после успешного OAuth callback и сохранения
токена. Последующие Reels публикуются прежним способом через Meta API,
а не автоматизацией браузера.

В панели пустые слоты скрыты. Для подключения нового Instagram-аккаунта
нажмите «Подключить Instagram · Meta 1 / Edge», выберите **любой**
свободный слот от 1 до 8 и завершите вход в открывшемся Edge.
Если аккаунты уже добавлены в первое Meta-приложение, добавлять их во
второе приложение **не нужно**. После успешного OAuth они появятся
в панели и очереди публикаций. Все сохранённые обложки остаются на месте.

Важно: для обеих Meta App зарегистрируйте соответствующие **точные**
HTTPS Redirect URI. Чтобы Reels могли получать видео и обложки, установите
`PUBLIC_BASE_URL` в действующий HTTPS-домен. Если используется Cloudflare Quick
Tunnel, его адрес может измениться после перезапуска.

### Туннель только для Instagram (Media + OAuth callback)

Публично открывать локальную панель на 8765 не требуется. Запустите
основное приложение на `127.0.0.1:8765`, затем gateway:

```powershell
.\\.venv\\Scripts\\python.exe -m uvicorn media_gateway:app --host 127.0.0.1 --port 8766 --no-access-log
```

В отдельном PowerShell:

```powershell
cloudflared tunnel --url http://127.0.0.1:8766
```

У gateway разрешены только `GET/HEAD /media/{token}` и
`GET /auth/instagram/callback`; он не публикует панель управления или
API Account Manager. Задайте HTTPS-туннель в `PUBLIC_BASE_URL` и
`INSTAGRAM_REDIRECT_URI` (с путём `/auth/instagram/callback`) для
**первого** приложения. В Meta for Developers этот адрес должен быть в
списке разрешённых OAuth Redirect URIs. `INSTAGRAM_REDIRECT_URI_2`
требуется только при отдельной авторизации через второе приложение.

При переходе с прошлой Tor-ветки **не нужно удалять** `.env`, `data/` или
`videos/`. Tor-переменные, если остались в локальном `.env`, в этой версии
игнорируются.

## Instagram — шаблоны описаний из локального TXT

Автоматические Instagram-описания теперь берутся **только** из файла
`data/instagram_caption_templates.txt`, а не из OpenAI или старых встроенных
текстов. Файл содержит 13 записей из предоставленного пользователем TXT;
каждая запись отделяется строкой `---`. Тексты (включая хештеги и эмодзи)
не редактируются. Для сочетания «название видео + слот аккаунта» выбирается
стабильный шаблон.

Сам TXT не выкладывается в публичный GitHub: папка `data/` исключена из
индекса Git. Чтобы установить шаблоны на своём ПК:

1. Скачайте `instagram_caption_templates.txt` из текущего чата.
2. Поместите файл по адресу
   `C:\Users\blackpansel\Desktop\postingttii\data\instagram_caption_templates.txt`.
3. Или, если исходный файл лежит в папке Downloads, выполните:

```powershell
cd "C:\Users\blackpansel\Desktop\postingttii"
New-Item -ItemType Directory -Force ".\data" | Out-Null
Copy-Item -LiteralPath "$env:USERPROFILE\Downloads\instagram_caption_templates (1).txt" -Destination ".\data\instagram_caption_templates.txt"
```

Путь можно переопределить переменной `INSTAGRAM_CAPTION_TEMPLATES_FILE`
в `.env`. Если путь относительный, он считается от корня репозитория.

Только Instagram использует шаблоны; генерация описаний для TikTok и YouTube
не меняется. В пакетной публикации тексты Instagram больше не создаются
через OpenAI. Если TXT отсутствует либо пустой, запуск Instagram-очереди
завершается понятной ошибкой, без подстановки постороннего текста.
Проверьте, что конкретный шаблон действительно подходит ролику:
некоторые записи в исходном TXT содержат названия брендов и утверждения
о конкретных произведениях.

## Meta 2 — отдельная вкладка без ручных номеров и вход через Dolphin

В Instagram-панели переключайтесь между **Meta 1** и **Meta 2**.
Существующие аккаунты Meta 1 остаются подключёнными, их токены и история
публикаций не затрагиваются.

Для нового аккаунта выберите **Meta 2 → + Добавить Instagram через Dolphin**.
PostingTTII автоматически выделит внутренний идентификатор (начиная с 9),
покажет локальную ссылку авторизации и по возможности скопирует её.
**Откройте выбранный профиль установленного Dolphin на том же компьютере,
вставьте ссылку в адресную строку и завершите Instagram OAuth.** При
необходимости выполните обычное подтверждение входа в браузере. После
успешного callback аккаунт с его именем появится во вкладке Meta 2 и в
существующей очереди публикации через Meta API. Номера вручную не вводятся.

Приложение не открывает Edge для новых подключений Meta 2, не управляет
профилями Dolphin, прокси, отпечатками браузера и не запрашивает логины,
пароли и коды 2FA. **Автоматический выбор/запуск определённого профиля Dolphin
потребует отдельной настройки**, потому что установка Dolphin не сообщает
PostingTTII, какой профиль нужно открыть. Вход выполняется через официальный
Meta OAuth, а не через автоматическое заполнение пароля.

Счётчик хранится в `data/instagram_meta2_last_slot.txt` и не сбрасывается
при удалении аккаунтов, чтобы историю публикаций не сопоставить с другим
аккаунтом. После OAuth каждый аккаунт получает индивидуальный токен в
зашифрованном TokenStore. Лимита в восемь записей в PostingTTII больше нет,
но сохраняются ограничения Meta API и разрешения приложения.

В `.env` должны быть заполнены `INSTAGRAM_CLIENT_ID_2`,
`INSTAGRAM_CLIENT_SECRET_2`, `INSTAGRAM_REDIRECT_URI_2`.
HTTPS redirect должен точно совпадать с разрешённым OAuth Redirect URI
**второй** Meta App. Публичный Cloudflare Tunnel направляйте только на
Media Gateway, порт 8766; не открывайте интерфейс 8765 в интернет.

Обложки новых аккаунтов доступны из карточек и в `/instagram-covers`.
Meta 1, старые обложки, TXT-описания, очередь и Telegram Studio не
изменяются. Не удаляйте локальную папку `data/`. Реальный вход через
Dolphin нужно проверить на Windows.

## Telegram Studio: рекламный баннер и превью 9:16

В Telegram Studio, под загрузкой фоновых видео, появился блок
**«Оформление Reels · баннер и кружок»**. В нём:

- вертикальная миниатюра **9:16** с одним из активных MP4-фонов и
  примером последнего скачанного Telegram-кружка (если оригиналов ещё нет,
  показывается заглушка);
- размер круга **1040 px по умолчанию**, с регулировкой **760–1080 px**,
  вместо прежних жёстко заданных 980 px;
- **хромакей только для рекламного баннера** (PNG/JPG/WEBP/MP4/WebM):
  **Telegram-кружок и видеофоны не затрагиваются**. Встроенная пипетка берёт
  цвет прямо с загруженного баннера или остановленного кадра видео-баннера.
  Можно выбрать другой цвет вручную (формат #RRGGBB), настроить
  чувствительность и мягкость краёв. В браузере показано приблизительное
  удаление цвета, а при реальном рендере FFmpeg chromakey применяется
  исключительно к входу баннера `[2:v]`. Без баннера хромакей не применяется.
  В прежних шаблонах сохраняются числовые настройки и зелёный по умолчанию
  #00FF00, но смысл опции теперь относится только к баннеру;
- необязательный рекламный баннер **PNG/JPG/WEBP (до 10 МБ) или
  MP4/WebM (до 100 МБ, длина до 10 минут)**, опция включения/выключения,
  регулировка ширины 100–1080 px, перемещение по миниатюре мышью или
  касанием; позиции сохраняются в пикселях **1080×1920**. Видео-баннер
  воспроизводится в превью и повторяется до конца рендера. В итоговом ролике
  используется исходный звук Telegram-кружка; звуковая дорожка баннера
  **не добавляется**. Видеофайлы проверяются через FFprobe;
- кнопки сброса позиции и удаления баннера.

Оформление сохраняется в существующем
`data/telegram_studio/config.json` (поле `render_design`), загруженный
баннер хранится в `data/telegram_studio/banners/`.
Оригинальные кружки и MP4-фоны не изменяются. На момент запуска
**«Скачать и смонтировать»** настройки фиксируются на всю партию.
Готовые ролики по-прежнему попадают в общую папку
`videos/inbox` для последующей публикации. Во время рендера
замена баннера и редактирование настроек заблокированы сервером.

Для загрузки изображений требуется Pillow (добавлен в
`requirements.txt`; устанавливается через `start.ps1`).
Реальное положение баннера и работа с альфа-каналом проверены на
тестовых фильтрах FFmpeg. Финальный UI на компьютере пользователя
пока требует проверки.

## Два независимых шаблона монтажа (Telegram и Instagram)

В Telegram Studio → **«✦ Конструктор оформления Reels»** имеются две вкладки:

**Telegram · кружки**
- Перемещайте кружок непосредственно мышкой по 9:16-миниатюре и меняйте его диаметр
  за белый маркер (или ползунком, 400–1080 px). Начальное расположение
  сохраняет привычный вид: 1040 px, X=20, Y=90.
- Выбирайте **«🔀 Смешивать фоны»** или **«▣ Один фон»**. Смешивание проходит
  по всем включённым MP4 фонам, чередуя их между следующими кружками
  (без повтора подряд, если фонов больше одного). Один фон использует
  строго выбранный активный файл. При единственном активном фоне смешивать
  нечего — он и будет использоваться во всех роликах.
- Обложки/баннеры PNG/JPG/WebP/MP4/WebM, хромакей, положение и размер
  баннера сохраняют прежнюю работу. Эти данные остаются в
  `data/telegram_studio/config.json`.

**Instagram · видео**
- Отдельная миниатюра 9:16 для **обычного Instagram-видео** (не кружка):
  мышкой меняются X/Y и размер видео (также доступен ползунок ширины).
  Перед рендером можно загрузить своё локальное видео для предпросмотра:
  этот файл не включается в очередь и не заменяет исходники.
- **Прозрачность обычного видео: 10–100%** над фоном, аудиодорожка
  оригинального видео сохраняется.
- **4 фоновых режима:** «🔀 Смешивать» (все включённые MP4 фоны по очереди),
  «▣ Один фон» (строго выбранный MP4), «◌ Размытие» (размытая копия
  исходного видео), «▯ Без фона» (тёмный холст без отдельного
  фонового клипа). Если в режиме смешивания нет доступных фонов,
  обработка автоматически использует размытие вместо ошибки.
- Настройки Instagram сохраняются **отдельно от Telegram** в
  `data/instagram_studio/sources.json` (поле `layout`). Добавленные
  ранее аккаунты, скачанные файлы, история обработанных видео и публикации
  не перезаписываются.

Выбор одного фона действует только на соответствующую вкладку.
В Telegram и Instagram можно установить **разные** режимы и фоновые
видео. Настройки фиксируются при старте каждой задачи монтажа, поэтому
изменения не влияют на уже запущенную очередь. Реальная публикация
по-прежнему использует основную очередь PostingTTII.
