# postingttii

Локальный мультипостер для коротких видео:

- 2× TikTok
- 2× Instagram Reels
- 2× YouTube Shorts
- папка `videos/inbox` как очередь на публикацию
- OpenAI генерирует описание и хештеги
- локальная панель управления в браузере

Проект использует официальные API платформ и OAuth. Секреты и токены не коммитятся в Git.


## Reels: контроль архива по просмотрам

Приложение автоматически проверяет последние 150 публикаций каждого подключённого через
Instagram Login аккаунта раз в час, пока запущен процесс FastAPI. Только для Reels,
опубликованных 24 часа назад или раньше, запрашивается официальная метрика Meta
views. При меньше 2500 просмотров Reel попадает в список
«Reels · контроль архива» внизу панели. Ролики с 2500+ просмотров не попадают
в список. Ошибка Meta или отсутствие статистики не считается нулём просмотров.

**Ограничение Instagram API:** у Meta нет официального endpoint для
«Архивировать Reel». Поэтому автоматическая проверка и очередь работают,
но сам Reel не архивируется автоматически. Перейдите по ссылке «Открыть Reel»,
архивируйте публикацию в Instagram, затем нажмите «Архивировано вручную».
Эта кнопка меняет только локальную запись, а не публикацию.
«Не архивировать» исключает выбранный Reel из очереди.

- Обработчик API: GET /api/reels-archive/status, POST /api/reels-archive/check
- Локальные действия: POST /api/reels-archive/mark-archived и POST /api/reels-archive/dismiss
- Локальные записи: data/reels_archive_state.json (токены доступа не сохраняются здесь)
- Проверка запускается в фоне после старта приложения и повторяется раз в 60 минут.
  Для непрерывных проверок FastAPI должен постоянно работать.
- В аккаунте должны быть разрешены instagram_business_basic и
  instagram_business_manage_insights. Если ранее подключённый аккаунт не даёт
  статистику, переподключите его, чтобы предоставить новое разрешение.
- Тесты: python -m unittest discover -s tests -p "test_reels_archive.py"

> Архивирование через приватный Instagram API не реализовано; автоматическое
> удаление не заменяет архивирование. Если Meta добавит официальный
> метод архивации, его можно подключить к этой очереди отдельно.
