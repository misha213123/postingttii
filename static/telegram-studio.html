03 / Подключение Telegram

Нужны TG_API_ID и TG_API_HASH в .env (my.telegram.org). Код приходит в твой Telegram. Никому его не передавай.

Открой Telegram на телефоне → Настройки → Устройства → Подключить устройство. Сканируй код только со своего компьютера.

04 / Автомонтаж Telegram

Скачиваются только выбранные в разделе 01 типы медиа: кружки или обычные видео. Кружки монтируются круглыми, обычные видео — прямоугольными по шаблону «Instagram · видео». Результаты сохраняются в выбранную папку публикации.

По умолчанию сначала старые сообщения, но можно выбрать новые или случайный порядок. Лимит действует на каждый канал; поиск ведётся среди последних 3000 сообщений.

Если выберешь аккаунт, при рендере применится его фон, заданный на главной странице. Можно выбрать привязанную к аккаунту папку.
Ожидание запуска

Оригиналы сохраняются без изменений. Готовые ролики не перезаписываются, повторные сообщения пропускаются.

05 / Instagram-источники
Вход в Instagram через Chrome
Откроется отдельный профиль Chrome для PostingTTII. Авторизация останется в этом профиле. После входа закрой отдельное окно Chrome перед запуском сканирования. Программа проверит видимые ссылки Reels на странице профиля; Instagram может ограничивать доступ.
Дополнительно: файл сессии Instaloader
Один раз создай файл сессии через Instaloader на своём ПК и загрузи его сюда. Пароль в студии не вводится.
Проверка...
Добавь ссылки на свои публичные Instagram-профили. Студия выбирает более старые ролики среди найденных, не скачивает обработанные повторно и монтирует без титров: размытие либо случайный фон TG Studio. Готовые MP4 появятся в общей очереди.


Фон конкретного аккаунта настраивается на главной странице PostingTTII.


Ожидание запуска
Для скачивания публичных видео используется yt-dlp. Instagram может ограничивать доступ; ошибки будут показаны ниже. Не требует ввода пароля Instagram.
