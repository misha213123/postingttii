Отдельный режим · без Meta API

Instagram · браузер

Браузерная публикация через Camoufox или Edge, выбор аккаунтов и видео, отдельные сессии

Этот режим не использует Meta Graph API и не управляет Meta 1 / Meta 2. Первоначальный вход в аккаунты выполняется вручную в выбранном браузере. Если Instagram запросит подтверждение, пройди его самостоятельно. Instagram может менять интерфейс или требовать подтверждение — в таком случае проверь публикацию самостоятельно.

01 / Добавить аккаунт

Чтобы использовать уже открытый Instagram, укажи папку профиля из launch.py. Закрой прежнее окно Camoufox и launch.py перед запуском из PostingTTII. Если поле пустое — создастся отдельный новый профиль.

Форматы: IP:порт:логин:пароль, http://IP:порт:логин:пароль или http://логин:пароль@IP:порт. HTTP/HTTPS с авторизацией и SOCKS5 без авторизации. После сохранения пароль скрыт.
