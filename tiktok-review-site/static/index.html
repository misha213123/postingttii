CREATOR PUBLISHING WORKFLOW

Publish your own short-form videos to your authorized TikTok accounts.

PostingTTII is a creator tool for selecting a video, reviewing its caption and TikTok publishing settings, and sending it to an account that the creator has explicitly connected.

HOW IT WORKS

A transparent TikTok publishing flow

The workflow is intentionally designed so the creator knows which account and content will be used before anything is sent to TikTok.

01

Authorize an account

Connect through TikTok Login and grant only the permissions required for profile identification and Direct Post.

02

Choose a video

Select a local video file that you own or have permission to publish. PostingTTII does not add promotional watermarks.

03

Review TikTok options

The app requests the latest creator information and displays only the privacy and interaction options available to that account.

04

Publish with consent

The creator explicitly confirms the upload. The app then reports TikTok's processing status back to the creator.

DATA MINIMIZATION

Only the TikTok data needed for publishing

PostingTTII uses authorized profile details to identify the selected account, access tokens to perform user-requested API actions, and current creator settings to render the publishing screen.

NO SILENT POSTING

The creator stays in control

Content is not sent in the background from this review flow. The creator selects the account, video and settings, then gives explicit consent for each Direct Post.

ACCOUNT CONTROL

Disconnect and delete

Connected TikTok authorization data can be removed from PostingTTII. Users can also revoke application access from TikTok.
